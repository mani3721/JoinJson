About this JSON merger

Built by joinjson.com, this free tool helps you combine JSON without sending files to a server. Join records by ID across many files and see every conflict.

What it does

Quick mode accepts two pasted or uploaded values. Advanced mode handles multiple files, nested record keys, list policies, source-aware conflicts, and CSV reports. It is intended for inspection and practical data cleanup, not as a substitute for application-specific validation.

How privacy works

File parsing and merging run in your browser. There is no upload endpoint, account system, analytics script, or live advertising code. Only theme and non-sensitive tool preferences use localStorage; file data never does. The web host still receives normal page and asset requests.
