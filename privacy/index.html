Local processing

Selected and pasted JSON is merged in browser memory. Local merging never uploads, logs, or automatically persists JSON, filenames, or results. Optional AI requests are described below. Copy and Download are explicit exports you request to your clipboard or device. Browser extensions, clipboard history, device software, and browser session restoration are outside the app’s control. Clear JSON inputs and results removes the current page data from the interface; this is not a forensic memory erasure guarantee.

Optional AI coding assistant

AI is separate from local merging. Selecting Ask AI after agreeing sends your prompt directly from your browser to Cohere using the site's configured API key. Requests do not pass through this site's AI proxy. Include context is off by default; enabling it also sends the current mode's JSON inputs, merge settings, and result. Filenames and previous requests are not included. Do not send secrets, personal data, or confidential records.

Prompts and responses stay in page memory, not app storage. The configured API key is embedded in public JavaScript and sent to Cohere for authentication; usage may be billed to the configured account. Anyone can inspect and reuse this key. This configuration is not suitable for public deployment; a server-side secret is needed to keep it private. Clear in the AI panel or Clear JSON inputs and results removes AI text and resets consent and context choices, but does not remove the configured key. This is not a forensic memory erasure guarantee. Stop cancels the local request but cannot recall data already sent. Review Cohere's retention, processing regions, and account limits before sending. Direct requests require Cohere to permit browser cross-origin access; the app cannot bypass those restrictions.

Examples and sharing

Examples are bundled static fixtures, loaded locally. Loading an example or shared input requires confirmation before replacing current inputs, with a 10-second in-memory Undo. No example, shared data, or Undo snapshot is written to app storage.

Copy link to this tool includes only the page address, without query or fragment data. Copy settings link includes only method, ID field name, records field name, earlier/later rule, list handling, and output format. Field names are visible to anyone with the link and, as query parameters, can appear in hosting request logs. Do not put sensitive information in field names. Unknown and invalid settings are ignored.

Share result sends the complete result as a JSON file to your chosen operating-system share target only after you request it. That target may upload or retain it outside this tool. Copy and Download remain available when native sharing is unsupported.

Share with data is off by default. Enabling it and requesting a link puts input JSON and the six settings above in the URL fragment (after #), without filenames or a separate result. The tool does not upload, log, or persist that payload. URL fragments are not sent in HTTP requests, but browsers, browser history/sync, extensions, clipboard history, messaging apps and link recipients may retain or read them. Compression is not encryption. Anyone with the link can read the inputs. Links over 8,000 characters are refused. Opening a shared-data link clears its fragment from the current address when possible, but cannot erase copies elsewhere. Never use this option for private data.

Exactly what localStorage contains

The only app storage keys are jm:v1:theme (system/light/dark), jm:v1:method (join/combine/deep), jm:v1:key (ID field name only), jm:v1:winner (later/earlier), jm:v1:lists (concat/unique/replace), jm:v1:format (pretty/compact), and jm:v1:caseInsensitive (boolean). There are seven keys. They contain no records, filenames, results, or pasted JSON. Do not put sensitive information in a field name. Invalid values are ignored and blocked storage does not prevent merging. Reset saved settings removes these keys without clearing other sites’ storage or your current inputs. Records path and keep-no-key are not persisted.
