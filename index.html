    Combine JSON files into one, without losing the story
    

    Use this browser tool to merge JSON files without sending your inputs to a server. You can merge JSON files online by pasting two values or adding files, then review the selected method before exporting. For larger jobs, merge multiple JSON files with explicit ordering and conflict rules in Advanced mode. Join customer records by a shared ID, combine independent lists, or preserve nested fields when merging settings objects. The result includes a conflict report that names the source files, so you can inspect competing values instead of guessing which one survived. Format check flags incompatible shapes and offers fixes near your inputs. Start with two small inputs if you want to understand the workflow before using larger files. Keep original files, review the output, and validate it against the requirements of the application that will consume it.
    
            
    
                Use Quick mode to merge 2 JSON files, or advanced mode to merge multiple JSON files with explicit
                rules. Joining matches records by an ID rather than simply appending duplicates. Non-conflicting
                fields are preserved, and every differing value encountered is recorded with its source. Array
                differences also appear in the report, including when arrays are combined.
            
    
            
    
                This JSON file merger works in memory. Review results before using them in production. It is not a
                streaming processor: very large files can exceed browser memory. JSON formatting changes on export,
                and numbers outside JavaScript’s safe integer range can lose precision. Keep large identifiers as
                strings.

    Python and command-line equivalents
    

    For repeatable local jobs, Python's json module can read files, combine lists and write a new output. Save the tested script from the Python JSON merging guide, then run python3 merge_json.py lists merged.json first.json second.json. That command appends lists; it does not join matching IDs. Object mode in that script is shallow. The guide explains those limits and links to recursive and keyed examples. Check syntax from your terminal with python3 -m json.tool merged.json; syntax validation does not replace schema checks.
    

    Frequently asked questions
    

    How do I merge 2 JSON files?
    Paste or upload one JSON value in each Quick mode box, then select Merge JSON. Auto-merge is on by default. The page explains the chosen method; review the result and conflicts before exporting.
    

    Can I merge multiple JSON files into one?
    Yes. Open Advanced mode, add files with the picker, drag and drop, or paste, then reorder them and select Merge JSON. Download the result as one JSON file.
    

    Are my files uploaded?
    Merging happens locally without uploading or saving JSON. Optional AI sends your prompt directly to Cohere using the site's configured API key, including only messages you type in the chat, never automatically attaching workspace JSON. Only theme and non-sensitive preferences use localStorage. Sharing and exports can expose data; read the privacy notice.
    

    What happens when values conflict?
    You choose later or earlier values. New fields are kept either way. Lists can concatenate, deduplicate, or be replaced. Review JSON merge conflicts with their source files in the Conflicts tab and export the report as CSV.
    

    Can I join JSON files using nested IDs?
    Yes. To join JSON files by ID, choose Join records in Advanced mode and use a dot path such as user.id. For wrapped lists, set the records field to data.items. The result is the merged list, not its original wrapper.
    

    Why does my JSON fail validation?
    JSON requires double-quoted keys and strings, no comments, no trailing commas, and matching brackets. Format check explains syntax or method problems and offers fixes. Use the reported line and column when available, correct the input, and try again.
    

    Is there a file size limit?
    There is no fixed tool limit, but browser memory and device speed limit practical size. Large merges use a local worker, but input checking and rendering can still take time. Preview is shortened at 50,000 characters; copies and downloads contain the full result. Keep large numeric IDs as strings to avoid precision loss.
