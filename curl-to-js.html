Generated Code Output

No requests are executed and no API keys are uploaded. Inputs remain in memory unless you explicitly choose Extract JSON to Merger: that stores only the JSON body locally for a one-time transfer, removed when the merger opens. Avoid sharing snippets containing secrets.

Convert cURL into Fetch or Axios JavaScript

Paste one cURL command copied from your terminal or browser developer tools. Choose Fetch for native async/await JavaScript, or Axios for a project that already installs Axios. Copy the result or download a JavaScript file.

Supported cURL options

Supports HTTP(S) URLs, quoted strings, line continuations, -X/--request, -H/--header, -d/--data, --data-raw, --data-binary, --user, and --get. Repeated data flags are joined with an ampersand as in cURL. Literal bodies are preserved without rewriting JSON.

Browser and shell limitations

Shell expressions, scripts, file uploads and unsupported flags are rejected instead of executed. Basic Auth accepts explicit ASCII username:password credentials. Browser CORS policies and forbidden headers still apply. Fetch cannot send a GET or HEAD body. JSON extraction is available only for a valid JSON request body. Generated code does not run automatically.
